# CoursVault - Premium Course Selling Platform

A complete multi-currency platform for selling premium courses at unbeatable prices.

## 🚀 Features

- **Multi-currency support** (USD, INR, PKR)
- **Course management** (Admin dashboard)
- **Order management** with manual verification
- **Payment proof upload**
- **Google Drive fulfillment**
- **WhatsApp integration**
- **Mobile-first responsive design**
- **SEO optimized**

## 📁 Project Structure

CoursVault/
├── backend/ # Node.js + Express API
├── frontend/ # React + Vite (Customer-facing)
└── dashboard/ # React + Vite (Admin panel)


## 🛠️ Tech Stack

- **Backend:** Node.js, Express, MongoDB, Cloudinary
- **Frontend:** React, Redux Toolkit, Framer Motion
- **Admin:** React, Redux Toolkit
- **Deployment:** PM2, Nginx
